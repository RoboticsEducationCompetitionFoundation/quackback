## 6. Cloud services; availability

Cloud features are optional conveniences and are not required to run an event; every cloud
feature degrades to fully offline operation when the network is unavailable. Cloud features
include:

- **Downloads and updates.** The Software may check for updates automatically; update
  check-ins transmit the installation details described in the Privacy Policy.
- **Launching from RECF Events.** An event can be launched from its RECF Events
  registration, pre-filling event details, registered teams, divisions, and offered awards.
  Fields sourced from RECF Events remain RECF's property (see Section 5) and may be
  read-only in the Software.
- **Cloud backup and recovery.** RECF Events-linked events are continuously replicated to
  RECF's cloud while the host computer is online, and can be restored onto another computer.
  Only one host computer may actively operate a cloud-linked event at a time; restoring an
  event onto a new computer supersedes the previous computer's connection. Local-only and
  practice events are not synchronized.
- **Results publication.** Events are private until you publish them. Publishing an event
  makes its results publicly available through RECF's public results API (with personal
  information removed, as described in the Privacy Policy) and includes the event in
  season-long public standings.
- **Finalization reporting.** At finalization, award winners and event completion status
  are reported to RECF Events.

We may modify, suspend, or discontinue any cloud feature at any time. Your use of the cloud
services must comply with these Terms and applicable law and must not interfere with the
cloud services or other users. Use of the public results API by third parties is subject to
separate terms.
